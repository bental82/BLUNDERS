# Working on this repo

- **Merge finished work into `main` and push it — don't ask first.** The owner asked for
  this to be the default.
- Before merging: if `app.js`, `style.css`, `index.html` or `data/` changed, rebuild the
  offline file with `python3 build/bundle.py`, and run the `build/verify*.mjs` suites
  (README → *Verification*) against a server on :8000.
